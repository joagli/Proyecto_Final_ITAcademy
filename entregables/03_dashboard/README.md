# 03 · Dashboard

- `dashboard.pdf`: todas las pestañas de la app (con los resultados de la hipótesis visibles y todas las capas y vistas del mapa), en páginas A4. Se genera con `python src/capturas.py` con la app abierta.
- La app en vivo se abre con `streamlit run app.py`: ver "Cómo ejecutar la app" en el README principal.

El dashboard se hizo en Streamlit en lugar de Power BI, con el acuerdo de la mentora.
